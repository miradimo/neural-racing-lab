# Дорожная карта

Переход между фазами — после обсуждения с пользователем. Ассистент реализует код
и объясняет внутреннее устройство; самостоятельное написание не обязательно.

| Фаза | Результат и критерий готовности |
|---|---|
| 0. Foundation | Изолированное окружение; реальный запуск CarRacing; random-agent; ручное управление; читаемое видео; тесты и документация; обсуждение с пользователем |
| 1. RL foundations | MDP, return, value, Bellman; REINFORCE на CartPole; объяснение policy gradient и его ограничений |
| 2. Actor-Critic и PPO | Rollout Buffer, TD, GAE, clipped loss; unit-тесты bootstrap/градиентов/форм; успешная проверка на CartPole |
| 3. Visual RL | Проверенные observation wrappers, CNN, frame stacking; forward pass и диапазоны данных; CarRacing discrete |
| 4. Training pipeline | Trainer, parallel envs, checkpoints, TensorBoard, независимый evaluation; замеры CPU/GPU; короткий согласованный training run |
| 5. Experiments | Равные бюджеты steps, несколько training seeds, независимые validation/test seeds; сравнения и ablations с разбросом |
| 6. Continuous control | Корректные bounded distributions и log-probability; тесты преобразований; сравнение с discrete |
| 7. Demo | Просмотр checkpoints, кривые, видео, Human vs AI; визуализация не мешает обучению |
| 8. Report | Методология, результаты, ограничения, архитектура и инструкции воспроизведения |

Общие критерии: код реализован, необходимые тесты действительно выполнены,
есть проверка на реальной среде, результаты задокументированы, принципы
обсуждены с пользователем и следующий шаг сформулирован.
