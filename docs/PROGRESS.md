# Текущий прогресс

Дата: 2026-10-27. Текущая фаза: **PHASE 0**.

## Выполнено

- Согласованы Python 3.12 + uv и подготовка инфраструктуры.
- Уточнён формат: ассистент реализует код, пользователь изучает теорию и задаёт вопросы.
- Диагностика: Windows 11 x64, i9-13980HX (24 ядра / 32 потока), около 32 ГБ RAM,
  RTX 4080 Laptop (12282 МиБ VRAM), драйвер 610.47, около 547 ГиБ свободно на C:.
- Созданы Git-репозиторий, структура пакета, CLI, тесты и документация.
- Написаны random-agent, manual control, проверка среды и CUDA.
- Создана .venv, зависимости установлены и закреплены в uv.lock.
- Python 3.12.14; Gymnasium 1.4.0; Box2D 2.3.10; PyTorch 2.12.1+cu126.
- `uv run --locked --extra torch ruff check .` — без ошибок.
- `uv run --locked --extra torch ruff format --check .` — успешно.
- `uv run --locked --extra torch pytest -q` — **16 passed in 5.07s**.
- `nrl-check` — реальная среда: observation (96,96,3) uint8, Discrete(5),
  render (400,600,3); CUDA доступна, матричное умножение сверено с CPU.
- Random baseline: seeds 42–44, по 1000 шагов; средний return −57.7473,
  выборочное std 7.5641. Все эпизоды завершились по TimeLimit.
- Видео записано: 1001 кадр / 50 FPS / 20.02 с. Начало, середина и конец
  декодированы; кадр из середины визуально проверен.
- Manual control: headless-тест и реальное окно с автоматическим выходом
  после 50 кадров прошли. Реальные нажатия человека пока не проверены.

## Статус

Техническая подготовка PHASE 0 выполнена. Полностью закрыть учебную фазу можно
после просмотра демо, ручной игры и обсуждения вопросов пользователя.
